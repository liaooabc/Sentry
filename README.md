# Sentry

常驻菜单栏的 App 更新检查工具。扫描本机已安装的 App，有新版就在菜单栏显示数量，点开可看「当前版本 → 新版本」和本次更新说明，需要时跳转到官方下载页。

只检查，不下载、不安装、不改动任何 App。

<img src="docs/panel.png" width="380" alt="Sentry 面板">

## 功能

- 菜单栏角标显示可更新数量，可关闭只留图标；左键开面板，右键出菜单
- 面板分「可更新 / 其他」两页；点一行就地展开更新说明，再点收起
- 「更新」按钮打开该 App 的官方下载页（App Store 产品页 / 官网 / GitHub Release）
- 右键任意一行：打开下载页、启动 App、在访达中显示、标记为最新、忽略
- 「全部更新」一次打开所有可更新 App 的下载页
- 扫描间隔 1 / 6 / 12 / 24 小时，面板收起后仍在后台扫描
- 通知只在清单发生变化时发送一次，点击可定位到对应行
- 设置内嵌在面板：通知、登录时启动、外观、扫描间隔、本软件更新
- 默认只比较正式版，可在设置中开启测试版

## 下载

- [最新版（Apple 芯片）](https://github.com/liaooabc/Sentry/releases/latest)
- 双击 dmg，把 Sentry 拖进「应用程序」
- 首次打开需按住 Control 点图标 › 选「打开」（未上架商店，只有临时签名）
- 要求：macOS 15 及以上，Apple 芯片（arm64）

## 说明

- 更新源按 App Store、官网 Sparkle feed、GitHub Releases 等逐层回退匹配；匹配不到的 App 标记「无检测源」，不计为「已是最新」
- 不修改、不移动已安装的 App，不写系统配置
- 常驻内存约 46 MB，单次检查峰值约 77 MB，检查结束回落
